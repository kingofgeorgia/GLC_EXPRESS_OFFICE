# ROADMAP

Технический roadmap по развитию сайта и CRM с грубой оценкой трудозатрат.

## Этап 1. Лиды и первичная обработка

Оценка: 1-2 дня

- [x] Добавить источник лида для заявок с главной страницы.
- [x] Ввести воронку лидов для заявок с главной: Новая, Связались, Ожидаем документы, В работе, Оплачено, Закрыто, Отменено.
- [x] Добавить ответственного менеджера для заявок с главной и редактирование этих полей в CRM.
- [ ] Расширить публичную форму заявки на главной: телефон, мессенджер, направление, тип груза, комментарий.

Результат:

- CRM видит не просто список входящих заявок, а управляемый lead inbox.
- Менеджер может зафиксировать владельца лида и текущий этап обработки.

## Этап 2. Работа менеджера внутри CRM

Оценка: 2-4 дня

- [ ] Добавить внутренние комментарии по заявке с датой и автором.
- [ ] Добавить задачи и напоминания по лидам и рейсам.
- [ ] Добавить фильтры по статусу, менеджеру, источнику и периоду.
- [ ] Добавить экспорт лидов и заявок в Excel/CSV.

Результат:

- CRM перестаёт быть только реестром записей и начинает поддерживать ежедневную операционную работу.

## Этап 3. Усиление конверсии сайта

Оценка: 2-3 дня

- [ ] Сделать калькулятор ориентировочной стоимости и сроков доставки.
- [ ] Добавить FAQ по срокам, оплате, документам и доставке.
- [ ] Добавить CTA-блок для WhatsApp/Telegram.
- [ ] Добавить секцию "Как мы работаем".

Результат:

- Сайт будет собирать более тёплые лиды и давать меньше однотипных вопросов менеджерам.

## Этап 4. Финансы и сделка

Оценка: 2-4 дня

- [ ] Добавить финансовый блок: сумма, предоплата, остаток, валюта, дата оплаты.
- [ ] Хранить документы сделки в одной карточке.
- [ ] Добавить шаблоны документов и быстрые выгрузки.

## Этап 5. Аналитика и масштабирование

Оценка: 2-5 дней

- [ ] Дашборд по лидам, конверсии и выручке.
- [ ] Аналитика сайта по формам и CTA.
- [ ] Подготовка перехода с LiteDB на SQL Server.
- [ ] Разделение прав по операциям.
